\noindent Sentinel (Social Media Threat Detection \& Security System) helps an ordinary social-media user judge a suspicious message, link or account before acting on it. It runs on the user's own computer and is used through a web app and a Chrome extension. For each kind of threat it shows what it found, what it could not check and what to do next. Learned models are used only after passing a fair test on data they have never seen.\\

\noindent\textbf{Main Components of Sentinel}
\begin{itemize}
\item \textbf{Web App and Chrome Extension:} check content, check accounts, view community warnings, save cases, and auto-scan chosen sites.
\item \textbf{Local Server:} a Python server that runs only on the user's computer and never opens submitted links.
\item \textbf{Fraud Rules:} detect money, OTP and urgency requests and suspicious links.
\item \textbf{Harmful-Language Rules:} 19 rules for English and Hinglish, with helpline advice for self-harm.
\item \textbf{Scam-Text Model:} a DistilBERT and TF-IDF model that gives a scam probability and the key words.
\item \textbf{Community Network:} users warn each other by sharing only anonymous fingerprints; a scam is published after 5 reporters.
\item \textbf{Bot Detection:} 25 behaviour signals from official APIs or uploaded data, plus a tested activity model.
\item \textbf{Case Store:} saved cases with signed receipts, export and deletion.
\end{itemize}

\noindent\textbf{Work Completed and Results So Far}
\begin{itemize}
\item \textbf{Testing:} 16 of 17 main test cases passed; 112 Python and 76 JavaScript automated tests pass.
\item \textbf{Scam-Text Model:} macro-F1 of 0.897 on 870 test SMS with no genuine messages flagged; false alarms on genuine Indian messages cut from 17 of 24 to 2 of 24.
\item \textbf{Community Network:} in a simulation of 10,000 users, protection rose from 78.2\% to 99.7\%, and no message text was found in the hub.
\item \textbf{Bot Detection:} the activity model passed its test (lowest AUC on unseen data 0.849); the profile-only model failed (0.600) and is not used.
\item \textbf{URL Models:} reached 97.07\% and 92.71\% F1 but flagged too many genuine links, so they remain research only.
\end{itemize}

\noindent\textbf{Future Work (Semester VIII):} test the scam model on real, consented Indian SMS; add newer bot data; move the community hub online with secure logins; and run a usability study with 15--20 volunteers.
